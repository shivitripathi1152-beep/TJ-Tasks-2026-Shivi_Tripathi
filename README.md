# StudySync

## Web Development Task – TechnoJam TJ-TASKS-2026

StudySync is a responsive student productivity website designed to help students organize assignments, deadlines, study goals, and academic progress in one place.

## Approach

The website was developed using:

- HTML5 for semantic page structure
- CSS3 for responsive styling and layout
- JavaScript for interactive functionality

The design focuses on a clean student-oriented SaaS interface with responsive sections for Home, About, Product, Testimonials, and Contact.

Interactive features include:

- Get Started onboarding modal
- Product workspace tabs
- Task planner interface
- Deadline calendar
- Goal analytics
- AI study assistant interface
- Responsive navigation
- Contact form interaction

## Features

- Responsive design for desktop and mobile
- Student dashboard preview
- Task and deadline organization
- Study progress tracking
- Interactive workspace
- Modern SaaS-style UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
